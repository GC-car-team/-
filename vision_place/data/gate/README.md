# data/gate · 桌面黄金样本说明

## 目录约定

```
data/gate/
  ring_print/     # 1:1 打印环图，用 MaixCAM 实拍（优先）
  ring_phone/     # 手机拍的圆环照（只验环号，不验毫米）
  color_proxy/    # 可选：纸片颜色冒烟（不可靠）
  labels.yaml     # 可选：期望值总表
```

## 文件名编码（最省事）

```
ring1_01.jpg      → 期望环号业务ID = 1
ring2_desk_a.png  → 期望 = 2
color1_red.jpg    → 期望颜色业务ID = 1
color6_lightblue.jpg → 期望 = 6
```

规则：文件名里**第一个连续数字**就是期望业务ID。  
`eval` / 人工核对都按这个读，避免手写错表。

## 每类最少拍多少（桌面）

| 集合 | 最少 | 拍什么 |
|---|---|---|
| `ring_print` | 每环 2 张 | 正对、略偏；同一相机高度 |
| `ring_phone` | 每环 1～2 张 | 现有手机照归档即可 |
| `color_proxy` | 可空 | 没真实物料就留空，别用纸片骗自己 |

## 明确不标的东西

- 不标毫米真值（桌面没有可信尺子几何，除非打印件 + 板载相机同高度）  
- 不把模型输出存成标签  
- 不把手机照的环心像素当上车真值  

## 拍摄纪律（用 MaixCAM 拍 print 时）

1. 相机高度用尺子量，写进文件名或 `labels.yaml`（例 `h320`）  
2. 曝光/白平衡锁定  
3. 同一高度拍完一轮再改高度  
4. 高度一改，旧的 mm 相关结论作废；环号分类结论一般还在
