# 蓝牙无线联调（整车）

网页经 **PC 蓝牙 COM → HC-05 → 主板 TUNE** 控制走直 / 转角 / 舵机 / 视觉命令。  
可选：相机 WiFi 只用于看帧（`maixcam_wifi_bench.py`）。

版本：`2026-11-04-bt3` · 端口 **8766** · 默认波特率 **9600**（与 `BT_BAUD` 一致）

## 准备

1. 电脑配对 HC-05；网页会优先标出 **HC-05** 对应 COM（本机曾为 **COM17**）  
   - 设置 → 蓝牙 → HC-05 → 若显示已连接更好  
   - 设备管理器 → 端口：找「蓝牙链接上的标准串行」；MAC 与 HC-05 一致的才是车上那路  
   - 多个空 COM（MAC 全 0）不要选  

2. 主板 `TUNE_ON_BT=1`，蓝牙已接 UART4  
3. 双击 `start.bat`，打开 http://127.0.0.1:8766/  
4. 健康检查：http://127.0.0.1:8766/api/health 应见 `"ver":"2026-11-04-bt1"`

## 页面用法

| 区 | 作用 | 下发命令 |
|----|------|----------|
| 连接 | 选蓝牙 COM，波特率 9600 | — |
| 底盘 | 走直 / ±90° / 急停 / 归零 | `G` `T` `X` `Z` |
| 舵机 | 开合、定位、到位合爪 | `O` `C` `U` `va` |
| 视觉 | 模式、过滤、跟瞄 | `vcXX` `ve` `vf` `v` |
| **相机+舵机配合** | 一键：张开→模式→过滤→跟瞄→轮询到位→合爪 | `O` `vc` `ve` `vf` `v` `va` |

### 配合测试（车上）

1. MaixCam 跑 **`视觉/main.py`**（接主板 UART7）  
2. 网页连蓝牙 → 「相机+舵机配合」选目标 → **开始配合**  
3. 看准星 / `dx,dy`；`arr=1` 后点 **合爪 va**（或勾选自动合爪）  
4. **停止** 会关跟瞄 `vf0`  

自定义一行可直接发任意 TUNE 文本。

## 注意

- 走直请用页面 **G**，不要用手机连发 `w`（会锁死歪掉的航向）  
- 舵机经主板 USART2，不再用「舵机测试板直连 PC」  
- 无主板时本页不适用；旧桌面直连舵机方案已由此版替代
