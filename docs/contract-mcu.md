# 给主控的契约一页（视觉端 MaixCAM Pro）

> 来源：`vision_place/contract.py`（代码是唯一真相）。改字段必须升 `cv` 版本。

## 链路

- 介质：UART，115200 8N1，ASCII 行，`\n` 结尾
- 视觉 → 主控：一行 JSON
- 主控 → 视觉：`SET:IDLE` / `SET:RING` / `SET:MAT`

## 消息字段

| 字段 | 含义 |
|---|---|
| `cv` | 契约版本，现 `"1.0"`。不匹配应直接报错 |
| `seq` | 帧序号 |
| `t` | 设备启动后 ms（单调） |
| `dt` | 本帧处理耗时 ms |
| `md` | `IDLE` / `RING` / `MAT` |
| `st` | `0=OK` `1=DEGRADED` `2=LOST`。**LOST 时禁止沿用上一帧** |
| `n` | 目标个数 |
| `tg[]` | 目标列表 |

### `tg[]` 每一项

| 字段 | 含义 |
|---|---|
| `c` | RING=环号 1-3；MAT=颜色 1-6（红黄蓝绿黑浅蓝） |
| `ex`,`ey` | mm，夹爪需沿机器人 +X/+Y 移动量（增量误差） |
| `ea` | deg，无旋转机构则 0 |
| `px`,`py` | 像素，仅调试 |
| `cf` | 置信度 0-100 |

## 约定

- 坐标系：机器人系，X 前、Y 左
- 连续 **200ms** 无新消息 → 主控必须停动作
- 样例：
  `{"cv":"1.0","seq":1,"t":1234,"dt":20,"md":"RING","st":0,"n":1,"tg":[{"c":2,"ex":-3.2,"ey":1.7,"ea":0.0,"px":412.3,"py":233.1,"cf":91}]}`

## K210 扫码（独立串口）

沿用既有协议：`$任务码#`，主控回 `$ACK#`。  
任务码格式：`156+123+516+231`（4 组三位数）。
