## 2. 扫码 Tab（v2 重写）

### 2.1 目标（你要的）

1. 扫码相机用**串口**与主板通信，走主板 **UART8**（不是物料相机 UART7）。  
2. 网页能**明确看到：主板已经收到并认可任务码**（不是只看相机屏 ACK）。

### 2.2 链路（目标架构）

```
扫码相机 (saoma 类固件)
    │  UART：$任务码# ；可选等 $ACK#
    ▼
主板 UART8  ——解析/校验——► 持有任务码（权威）
    │
    ├─（可选）回 UART8：$ACK#
    └─ 蓝牙 TUNE 文本 ──► 桌面联调 server ──► 网页「已收到」
```

与现网差异（必须写清）：

| 项 | 现状 | v2 目标 |
|----|------|---------|
| 收口 | `$…#` 解析挂在 **vision.c / UART7** | 改到（或并行）**UART8 扫码模块** |
| 相机程序 | 锁定 `main.py` 无扫码；仓库有 `视觉/saoma.py`（K210 风格，`$ACK#`） | 扫码相机跑扫码固件，接 UART8 |
| 网页确认 | 无 | 听 BT 上报的已持有码，大字 + 拆组 +「已收到」 |

### 2.3 任务码格式（沿用现校验）

- 帧：`$` + 15 字符 + `#`  
- 例：`156+123+516+231`  
- 校验：三段 `+`；物料位 `1–6`；环号位 `1–3`（与现 `vision_qr_ok` 一致）

### 2.4 主板侧（实现阶段才做；本文件先定口径）

推荐新建独立模块（名暂定 `scan.c` / `Scan_*`），避免和物料视觉抢 UART7：

| 项 | 建议 |
|----|------|
| 口 | `UART8`（引脚/波特率见 §4） |
| 收 | 字节状态机：`$`…`#`，校验通过 → 写入持有缓冲（不消费） |
| 回执 | 校验通过后对 **UART8** 发 `$ACK#`（对齐 `saoma.py`） |
| 持有 | 码保存在 MCU，直到 `vc` 清码命令或被新码覆盖 |
| 查询 | **`vs`**：不消费，回 `CODE,<task>\r\n` 或 `CODE,NONE\r\n` |
| 主动推 | 校验通过后经 TUNE/BT **主动**一行 `CODE,<task>\r\n`（S3A） |
| 与 route | `route_run` 扫码工位改读 `Scan_*` 持有缓冲，不再从 UART7 拿码 |

**网页确认路径（核心）：**

1. 扫码相机 → UART8 → MCU 持有 →（主动）BT `CODE,...`  
2. 网页监听 / 点「查询」发 `vs` → 显示码 + **「主板已收到」**  
3. 无码 → 「等待中」

### 2.5 网页 Tab「扫码」

| 区块 | 行为 |
|------|------|
| 状态灯 | 等待中 / 主板已收到 / 校验失败（若 MCU 回报 ERR） |
| 任务码大字 | 最近一次 MCU 回报的完整 15 字符 |
| 四组拆解 | `156 \| 123 \| 516 \| 231` |
| 查询 | 按钮 / 自动轮询（建议 500ms，仅本 Tab 打开时） |
| 清空 | 清网页缓存；若有 MCU 清码命令则一并发 |
| 说明 | 物料相机 UART7 与本页无关；扫码相机接 UART8 |

**不做：** 网页模拟注入假码冒充「主板已收到」（避免假阳性）。真要测 UI 可用「高级 → 原始 TUNE」看回执，但不标成已收到。

### 2.6 Server

- `bt_loop`：解析 `CODE,` → `state["scan"] = {code, t, ok}`  
- `GET /api/status` 带上 `scan`  
- `POST /api/scan/query` → 发查询命令（`v` 或新命令）  
- 升降 API 与扫码 API 分文件逻辑清晰即可  

### 2.7 与锁定视觉的关系

- **不改** `视觉/main.py`  
- 扫码相机固件：以现有 `saoma.py` 协议为准（`$…#` + 等 `$ACK#`）；若实际板是 MaixCAM，需另移植同协议（实现阶段确认机型）

### S1（按主板工程同步 —— 你授权「根据主板信息直接同步」）

在 `config.h` / `usart.c` / 引脚速查里检索：

| 口 | 工程记载 |
|----|----------|
| UART7 视觉 | **已配置**：`PE8(TX)` / `PE7(RX)`，**115200 8N1** |
| UART8 扫码 | **未配置**（无 `huart8`、无 MSP、无 config 宏） |

因此 S1 **无法从现有宏抄到现成引脚**，只能按同板惯例推断：

| 项 | 同步结论（待你对丝印一锤） |
|----|---------------------------|
| 外设 | `UART8` |
| 引脚（F429 AF8 默认） | **PE1 = UART8_TX**，**PE0 = UART8_RX**（与 UART7 同在 GPIOE，最可能是「串口8」排针） |
| 波特率 | **115200 8N1**（对齐 UART7 / `saoma.py`） |
| 接线 | 相机 TX→**PE0(RX)**，相机 RX→**PE1(TX)**，共地 |

若板上丝印「串口8」不是 PE0/PE1，实现前改 `config.h` 两行宏即可。
