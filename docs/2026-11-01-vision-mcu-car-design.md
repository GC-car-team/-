## 1. 物理与帧格式（A1 / A2，已确认）

- 口：UART7，115200；MaixCam UART2 交叉，共地。
- 视觉→板：

| 类型 | 帧（大端） |
|------|------------|
| 物料 | `B3 B3 B1 xH xL yH yL r color 5B` |
| 圆环 | `B3 B3 B2 xH xL yH yL digit 00 5B` |

- `color`：业务色号 1–6；`digit`：业务环号 1–3（视觉已真实上报）。
- **废弃**：`AA 55` / `AA 56` / 到位 `32767`。

## 2. 板→视觉命令（A3，已确认）与赛场交流过程

### 2.0 工位 ↔ 视觉模式（必守）

| 工位 / 动作 | 视觉模式 cmd | 主板只接受的上报 | 备注 |
|-------------|--------------|------------------|------|
| 启停 / 行驶途中 | 可不发或保持上一模式 | 不用于伺服 | 精对准前必须重发正确 cmd |
| 扫码 | 不占用 `01/02/03~08` 物料环逻辑 | `$任务码#`（若走该口） | 与检测模式分离 |
| **原料区抓取** | **单色 `03~08`**（当前任务色） | **仅 `B1` 且 `color==C`** | 禁止用 `02`；可选接近时短时 `01` 预览，对准前改单色 |
| **粗加工区 放置** | **`02` 圆环** | **仅 `B2` 且 `digit==N`（R1）** | 禁止用物料单色 |
| **粗加工区 抓回** | **`02` 圆环** | **仅 `B2` 且 `digit==N`** | 同上 |
| **暂存区 放置 / 码垛** | **`02` 圆环** | **仅 `B2` 且 `digit==N`** | 同上 |
| 车上放料（盘位） | 一般不依赖视觉伺服 | — | 靠 GM6020 示教角；若以后要视觉再单开 |

切换规则：

1. **进工位精对准第一步 = 先 `Vision_SendCmd(正确模式)`**，再读帧伺服。  
2. 离开该工位或改目标色/环时：**再发一次**新 cmd，避免视觉仍停在旧模式。  
3. 伺服循环内：帧类型与模式不符（如环区收到 `B1`）→ **丢弃**，不计到位。  
4. `route_run` 实现时按工位表显式绑定模式，禁止沿用旧「TASK1/2/… 隐式模式」。

### 2.1 命令字（与锁定视觉一致）

| cmd | 含义 |
|-----|------|
| `0x01` | 物料模式，全色 |
| `0x02` | 圆环模式 |
| `0x03`~`0x08` | 物料单色（按下表） |

业务色号 → 命令（与视觉 `CMD_COLOR_MAP` + HSV 表一致）：

| 色号 | 颜色 | cmd |
|------|------|-----|
| 1 | 红 | `0x03` |
| 2 | 黄 | `0x07` |
| 3 | 蓝 | `0x05` |
| 4 | 绿 | `0x04` |
| 5 | 黑 | `0x06` |
| 6 | 浅蓝 | `0x08` |

帧格式：`FF <cmd> FE`。  
**不再使用**手册 4.0 的 `0F/1F/2F/3F/4F/5F/6F`。

### 2.2 任务码谁管什么

例：`156+123+516+231`

- 主板解析并保存四组；全程**以任务码为权威**。
- 第一批抓色顺序：`1→5→6`；第一批放环：`1→2→3`；第二批同理。
- 视觉**不解析任务码**（扫码若仍走相机转发 `$…#`，主板收码后自行调度）。

### 2.3 原料区抓取（颜色交流）

对「当前应抓颜色 C」每一步：

1. 车到原料区粗位（主板里程/示教）。
2. 主板发 `FF <色号对应cmd> FE`（如抓红发 `03`），视觉进入「只认该色」。
3. 视觉连续上报 `B1`：`(x,y,r,color)`。
4. 主板：**只采用 `color==C` 的帧**做中心伺服；其它色丢弃。
5. `|ex|,|ey|` 小于阈值 → 主板自判到位（A4）→ 升降 → 总线舵机合爪 → 回程放车上。
6. 下一色重复 2–5；三色抓完再离开原料区。

可选：接近前先发 `01` 全色预览；正式对准必须切到单色 cmd。

### 2.4 粗加工 / 暂存放环与抓回（环号交流，A5=R1）

对「当前目标环号 N」每一步：

1. 主板按任务码取 `N`，走到 `ring_pose[N]` 粗位（示教表，与视觉无关）。
2. 主板发 `FF 02 FE` → 圆环模式。
3. 视觉上报 `B2`：`(x,y,digit)`。
4. **R1**：
   - 调度目标 = 任务码中的 N（不是视觉选环）。
   - 精对准只使用 `digit==N` 的帧；`digit≠N` → 丢弃，可计数，超限报警/重试。
   - 若长期无 `digit==N`：超时策略（重定位 / 记失败），不盲跟错误 digit。
5. 中心到位 → 升降 → 开合（放或抓）→ 回程。
6. 下一环重复。

码垛（第二批暂存）：环号仍来自任务码/同色位；视觉同样 `02` + R1 校验。

### 2.5 时序示意（第一批摘要）

```
扫码 → 主板持有任务码
→ 原料: 发单色cmd → 收B1(color匹配) → 到位 → 抓 ×3
→ 粗加工放: 发02 → 收B2(digit==任务环) → 到位 → 放 ×3
→ 粗加工抓回: 同上抓
→ 暂存放: 同上放
→ 第二批重复（暂存为码垛）
```

### 2.6 视觉侧已知限制（主板必须兜住）

锁定视觉在圆环模式**不会**按环号过滤，可能上报最高分数字框。  
R1 + §2.0：主板必须丢弃 `digit≠N` 的 `B2`；原料区必须丢弃 `color≠C` 的 `B1`。  
视觉按环号过滤属解锁后增强，不在本次主板必做范围。

## 5. 主板改造与清淤（C）

实现时**删除或抽空**所有与新契约冲突的过时路径，避免双轨并存：

- `vision`：`AA55/AA56`、旧 `VISION_CMD_TASK*`、`VISION_ARRIVED`
- 夹爪：`servo` PWM 脉宽体系、`motor` MG370、tune `U/O/C/K` 脉宽与直流段
- 臂：齿条轴、丝杆导程假设、工位表 `'R'`、双轴定标中仅服务伸缩的部分
- 路线：手册 4.0 命令切换逻辑；改为 `01/02/03~08` + R1
- 注释/config 中过时说明一并改掉，避免后人按旧方案接线

保留：GM6020、底盘步进、IMU、HMI 等与本改造无关且仍使用的模块。

建议实施顺序：

1. `vision.c/h` 新协议 + 假帧自测  
2. `bus_servo` + 删旧夹爪  
3. 单轴升降 + 工位表  
4. `route_run` 接 A3/A4/R1  
5.（并行）桌面相机+舵机网页 P0~P2

## 6. 验收要点（主板侧）

- 假 `B1/B2` 能解析；发色/环命令与表一致  
- **工位模式**：原料只发 `03~08` 且只跟 `B1`；环工位只发 `02` 且只跟 `B2`；错类型帧不推动作  
- 单色抓：只跟匹配 `color`  
- 放环 R1：只跟匹配 `digit`；错 digit 不推动作  
- 无 PWM/MG370/齿条残留引用；编译干净  
- 开合仅总线舵机两点位
