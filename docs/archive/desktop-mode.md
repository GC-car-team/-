# 桌面模式推进清单（无场地 / 无标准物料 / 仅有手机圆环照）

> 前提：不能去场地；桌上模拟；没有正式 3D 打印物料；圆环目前只有手机照片。
> 目标：在这些限制下，把**还能验证的部分全部验证掉**，把必须等实物的部分显式记账，避免假进度。

---

## 0. 先分清：桌面上什么可信、什么不可信

| 事项 | 桌面能否验证 | 说明 |
|---|---|---|
| 契约编码 / 串口协议 / 模式切换 | **能** | 不需要场地 |
| `class_id → 业务ID` 映射 | **能**（有条件） | 需要模型在 MaixCAM 上对「能看见的目标」跑起来 |
| 数字模型能否认出 1/2/3 | **能** | 用**按真实尺寸打印的环图**最好；手机照片次之 |
| K210 扫码距离 / 多帧确认 | **能** | 自己打印二维码 |
| `calib scale`（mm/px 初值） | **能** | 打印一对已知间距标记 |
| 颜色模型（尤其蓝/浅蓝） | **弱 / 基本不能** | 没有真实物料，纸片颜色和 3D 打印色差不是一回事 |
| 黑物料 vs 黑障碍 | **不能** | 训练集也没同框；必须等实物 |
| ±4mm / 精修是否够用 | **不能当真** | 手机照片几何 ≠ MaixCAM；打印件也没有真实 φ |
| 底盘伺服 / 延迟 / 上车成功率 | **不能** | 必须有车+场地 |

**铁律**：桌面通过 ≠ 赛场通过。桌面只证明「软件链和粗识别」；精度与色差要等实物。

## 1. 本周推荐顺序（全部可在桌上完成）

### 步 A · 打印件（今天就能做，性价比最高）

不要只靠手机照片。**按 1:1 打印**下面几样（缩放必须关）：

1. **环台靶标**：按图二，台面 580×150，三环心距 150 mm，数字 1/2/3，尽量画出外虚线环  
2. **100 mm 刻度条**：两个清晰标记，间距用尺子量准（别信打印）  
3. **任务二维码**：内容例如 `156+123+516+231`，码面尽量接近 **80×80 mm**

> 手机照片可以留作「数字识别回归样本」，但**不要用它当毫米精度的真值**。

### 步 B · 板上验证映射（最重要，半天）

1. 把打印环图平放桌上  
2. MaixCAM 固定高度（ recorde 下来：尺子量相机到纸面距离）  
3. 填 `MODEL_CONF_TH` / `MODEL_IOU_TH`（先试 0.45 / 0.45）  
4. 跑验证脚本：屏幕上画框，旁边写**业务ID**（不是 class_id）  
5. 验收：
   - 对着数字「1」→ 输出 `c:1`
   - 「2」→ `c:2`，「3」→ `c:3`
6. （可选）把手机圆环照拷到板子 `data/gate/ring_phone/`，再跑一遍，只验收「环号对不对」

**这一步不过，后面所有数据都不可信。**

### 步 C · K210 扫码实测（1～2 小时）

1. 贴上打印的 80 mm 二维码  
2. 从 1.2 m 每次靠近 10 cm  
3. 分别记 QVGA / VGA（若你改分辨率）第一次连续 3 秒稳定 `TASK` 的距离  
4. 写进 `vision_qr/README.md`

### 步 D · 尺度标定初值（不需要车）

```bash
python calib_task.py scale --len-mm 100
python calib_task.py phys --height-mm <你量的高度> --pitch-deg <估计俯角>
```

得到对角矩阵。**只能用于桌面粗测，不能当上车标定。**

### 步 E · 建「桌面 gate」文件夹（只标业务语义）

见 `vision_place/data/gate/README.md`。  
桌面 gate **只验收**：检出/漏检、环号对不对、颜色号对不对（若有纸片）。  
**不验收**：毫米误差、精修、蓝浅蓝色差。

### 步 F · 明确暂停项（写进 gaps，避免焦虑）

| 暂停项 | 等到什么 |
|---|---|
| 蓝/浅蓝可靠性 | 真实 3D 打印物料 |
| 黑障碍负样本 | 黑色 Φ50 圆柱实物 |
| ring_fit 精修是否够 1 环 | 真实环台 + 定高相机 |
| `dir` 方向标定 | 机构能动一次 |
| L4/L5 | 车 + 场地几小时 |

## 2. 手机照片怎么用才正确

**可用**
- 检验数字模型在「非训练分布照片」上能不能认出 1/2/3  
- 做 class_id→业务ID 的肉眼对照样本  
- 以后有 `eval_task` 时做「环号分类准确率」

**不可用**
- 当毫米真值（手机内参、畸变、拍摄距离都与板载相机不同）  
- 当精修算法的验收（环线在手机图里的像素尺度乱）  
- 当颜色模型验收（光照/白平衡完全另一套）

拷贝建议：

```
vision_place/data/gate/ring_phone/
  ring1_01.jpg    # 文件名编码期望环号
  ring2_01.jpg
  ring3_01.jpg
```

## 3. 没有标准物料时，颜色怎么办

| 做法 | 价值 | 风险 |
|---|---|---|
| 彩打纸片红黄蓝绿 | 只能测「模型能不能出框」 | **测不了蓝/浅蓝**；纸和 ABS/PLA 差很大 |
| 等真实物料 | 唯一可靠 | 要等 |
| 只用颜色模型的自测映射表 | 证明代码映射对 | 不证明现场识别对 |

**建议**：颜色链路先只做「代码能加载模型 + 映射表自测通过」；纸片最多做冒烟，不要据此调阈值。
