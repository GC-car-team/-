# 桌面联调（无整车 / 无主板）

你手头：**总线舵机 + 舵机测试板 + MaixCam（可选串口）**。  
网页在 PC 上当主控；**不改视觉算法**。

## 接线

1. **舵机（必接，P0）**  
   舵机 → 测试板 → USB-TTL → PC 某一 COM。  
   波特率 115200；协议 `#000PxxxxTtttt!`。

2. **视觉（推荐 WiFi，P1/P2）**  
   - USB 线插电脑 **通常不会出现 COM 口**（正常现象，不是网页坏了）。  
   - 相机 Settings 连上与电脑**同一 WiFi**，记下 IP。  
   - 用 MaixVision 运行 **`桌面联调/maixcam_wifi_bench.py`**（是副本，**不改** `成品/视觉/main.py`）。  
   - 屏上会显示 `IP:5555`；网页填「相机 WiFi IP」→ 连接。  
   - 仍可用 USB-TTL 接相机 UART 当串口，但桌面联调优先 WiFi。

舵机 COM 与视觉 WiFi 互不影响：只连舵机也能 P0；只连 WiFi 也能看帧。

## 运行

双击 `start.bat`，或：

```bat
cd /d C:\Users\起名字太难了\Desktop\成品\桌面联调
pip install -r requirements.txt
python server.py
```

浏览器打开：**http://127.0.0.1:8766/**（端口 **8766**）  
先打开 http://127.0.0.1:8766/api/health 应看到 `"ver":"2026-11-01-wifi2"`。  
不要双击 `index.html`；不要再用旧的 8765。

页面上方会显示「扫到 N 个」；若为空可点「刷新口」，或手动填如 `COM12`。  
在 Windows「设备管理器 → 端口(COM和LPT)」核对 CH340/CP210x 口号。

**当前无主板/整车**：只做 P0 舵机 +（可选）P1/P2 视觉串口即可。

## 测试顺序（可重复）

| 阶段 | 做什么 | 通过 |
|------|--------|------|
| P0 | 只连舵机口 → 张开/合紧 10 次 → 急停 → 复位 | 状态回 idle，不卡死 |
| P1 | 再连视觉口 → 点「02 圆环」或单色 → 看坐标/digit/color | 日志有 RX |
| P2 | 看到目标后点「确认合爪」 | 合爪一次；连续点只跟最后意图 |

标定：用「自定义 P」找到开合位置后，可 `POST /api/calib` 写入本次进程的 open/close（重启恢复默认 2000/600）。正式值以后写回主板 `BUS_SERVO_OPEN_P/CLOSE_P`。

## 防卡死

- 双串口隔离；读超时 50ms  
- 舵机状态机 `idle/moving/fault`；急停后需「复位」  
- 指令覆盖，无长队列
